## 2. Thông Tin Đề Tài

- **Tên đề tài:**
Xây dựng hệ thống nền tảng tìm việc làm trực tuyến (Job Portal)

- **Mô tả ngắn:**
Hệ thống Job Portal là một nền tảng web giúp kết nối giữa ứng viên và nhà tuyển dụng. Ứng viên có thể tìm kiếm công việc, upload CV và ứng tuyển trực tuyến, đồng thời theo dõi trạng thái ứng tuyển. Nhà tuyển dụng có thể đăng tin tuyển dụng và quản lý hồ sơ ứng viên.

- **Đối tượng sử dụng:**
  - Ứng viên (Candidate)
  - Nhà tuyển dụng (Employer)
  - Quản trị viên (Admin)

---

## 3. Tính Năng Chính (MVP)

###  Ứng viên
- Đăng ký / đăng nhập
- Tìm kiếm việc làm
- Xem chi tiết công việc
- Upload CV (PDF)
- Ứng tuyển trực tuyến
- Theo dõi trạng thái ứng tuyển
- Xem danh sách job đã apply

### Nhà tuyển dụng
- Đăng nhập hệ thống
- Tạo / sửa / xóa job
- Xem danh sách ứng viên
- Duyệt / từ chối hồ sơ

### Hệ thống
- Xác thực JWT
- Phân quyền USER / EMPLOYER / ADMIN
- RESTful API
- Upload file CV

---

## 4. Công Nghệ Sử Dụng

- Backend: Spring Boot (Java)
- Frontend: ReactJS
- Database: MySQL
- Authentication: Spring Security + JWT
- API Testing: Postman
- Other: Git, REST API
